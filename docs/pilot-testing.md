# Pilot test with one distributor

Do not interpret this build or fictional demo as evidence of demand.

## First experiment

Ask one flooring or tile distributor for five recent, redacted enquiries, the catalogue used for each, and the quotations actually prepared. Observe one employee handling another enquiry without Quolyn. Record search steps, corrections, unit conversions, missing information and actual active work time. Obtain permission before importing real customer information.

Then process the same five enquiries with the distributor reviewing every match. The riskiest assumption is that the catalogue contains enough trustworthy specifications and price bases to make suggestions useful. If catalogue cleanup dominates the work, first sell a bounded catalogue-cleanup and quotation-assistance service instead of expanding the software.

## Evidence to record

| Evidence | Record |
|---|---|
| Repeated pain | Specific requests, frequency, where work stalls |
| Existing cost | Staff work, paid software or outsourced services |
| Match quality | First suggestion selected, replacement, no candidate |
| Review effort | Corrections and unresolved requirements |
| Quote quality | Unit/price/specification errors before and after review |
| Commercial commitment | Named owner, date, paid pilot amount or explicit refusal |
| Repeat use | A second real enquiry without prompting |

Elapsed timestamps are not active labour time. Do not claim time saved without a measured baseline.

## Fictional walkthrough

1. Register and create a workspace. For the demo, use “Northfield Surfaces (fictional)”.
2. Set a fictional distributor address in Settings. Currency INR, tax-exclusive prices.
3. Load fictional demo data in Settings. Existing products are not replaced.
4. Open the ambiguous flooring enquiry. Analyse it in deterministic mode. Observe missing material, underlay/trim quantities and relative delivery date. No accessory quantity should be invented.
5. Open the complete 100 m² porcelain example. Analyse it, select NF-POR-01, confirm exact SKU and requirements, and exclude non-product instruction lines with reasons. Record clarification answers and save each review.
6. Create a quotation draft, review its included line, and save. With 42 boxes at ₹1,200, 5% customer discount and 18% tax, the total is ₹56,498.40.
7. Mark ready; preview and download PDF and CSV. Record “sent” manually only after you send it yourself.
8. Change an issued quote. Verify a new revision is created and the original remains unchanged.

## Decision rule

Continue only if the distributor gives repeated real enquiries and pays for a bounded assisted pilot. A compliment, demo signup or “AI looks useful” is not purchase evidence. If requirements cannot be resolved reliably or the employee spends more time correcting suggestions than searching, modify the workflow before adding features.

## Before production

Configure email delivery and confirmation/recovery URLs on the intended hosting origin. Enable leaked-password protection if available in the selected plan. Verify backup/restore, retention/deletion, operational monitoring and support responsibilities. Load-test imports and search using an actual 10,000-product catalogue. Review legal/tax treatment for the distributor's jurisdiction with qualified people. Configure AI only after agreeing which customer data may be sent to the provider.
